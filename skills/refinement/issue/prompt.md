The added file is a work item (a GitHub issue), not code. Review it for readiness to build:
- acceptance criteria that cannot be tested, contradict each other or contradict the description
- missing non-functional requirements the change clearly needs (performance, security, data retention, audit)
- scope that is really several items, or hidden dependencies on other work
- ambiguous references ("the button", "the usual way", "like before") a newcomer could not resolve
- bug reports whose steps, expected or actual behaviour do not match each other
Cite the line of the issue text where the problem is. Report only what a careful refiner would raise.
